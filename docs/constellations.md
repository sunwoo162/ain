# 의심암귀 V0.7 — 별자리 탐색과 시맨틱 줌

## 중요한 용어

**연결 묶음(Connected cluster)**은 저장된 노드와 연결 관계만 사용해 계산하는 무방향 연결 요소입니다. **한 연결 묶음이 반드시 한 번의 AI 실행이라는 뜻은 아닙니다.** 실행 사이에 실제로 기록된 수동 링크나 도구 관계가 있으면 여러 실행이 한 묶음으로 합쳐질 수 있습니다. 이 기능은 모델의 내부 추론이나 원인 관계를 추정하지 않습니다.

## 사용 방법

1. 그래프 화면 상단 **흔적을 은하처럼. / CONSTELLATION NAVIGATOR**에서 연결 묶음을 선택합니다.
2. 선택한 묶음의 실제 노드와 연결만 중앙 캔버스에 표시됩니다. 우측 상세 패널·관계 렌즈·경로 탐색은 계속 사용할 수 있습니다.
3. **전체로 돌아가기**로 모든 연결을 다시 표시합니다.
4. 기존 검색·노드 종류·시간 필터를 먼저 적용합니다. 묶음 목록과 묶음 안의 노드 수는 필터된 데이터 기준이며, 누락된 정보를 복원하거나 가짜 연결을 추가하지 않습니다.
5. 확대/축소에 따라 **은하 조망 → 관계 탐색 → 세부 분석**의 표시 밀도가 바뀝니다.

## 시맨틱 줌

| 상태 | 변경 사항 |
| --- | --- |
| 은하 조망 | 중요한 질문·모델·답변 노드의 제목을 위주로 표시. 관계선 강조를 낮춰 시각적 혼잡 완화 |
| 관계 탐색 | 일반적인 노드 제목과 연결 구조 표시 |
| 세부 분석 | 노드 제목 가독성을 높이고 실제 기록된 선을 더 선명하게 표시 |

줌 상태 사이에는 약간의 완충 구간(hysteresis)을 두어 터치패드로 배율 경계에 있을 때 글자가 깜빡이지 않도록 했습니다. **줌은 데이터 필터가 아닙니다.** 노드·엣지 개수와 원본 저장 데이터는 확대/축소로 변하지 않습니다.

## UI·성능 정책

- 한 번에 최대 600개 노드·1,800개 관계를 그리는 V0.4 예산은 유지합니다.
- 묶음 선택 시 검색 범위를 줄이되, 원본 데이터를 삭제하거나 병합하지 않습니다.
- 클러스터 ID는 실제 노드의 ID에서 파생되며 가상의 그래프 노드를 추가하지 않습니다.
- 클러스터 카드 수는 최대 5개만 표시합니다. 초과 시 필터로 범위를 좁힐 수 있습니다.
- 모션 감소 설정에서는 장식용 이동 전환을 비활성화합니다.
- `Ctrl/⌘+K` 검색, 근거 경로 탐색, Live connect 등 기존 기능을 그대로 유지합니다.
- CI에서 노드 분리·수동 연결·클러스터 안정성·시맨틱 줌 전환 및 Chromium 데스크톱·모바일 탐색을 검증합니다.

## 한계

이 단계에서는 연결 요소를 기반으로 묶음을 보여주며, OpenTelemetry의 명시적 trace ID와 span ID 또는 provider run ID로 그룹화하지 않습니다. 대규모 유저 데이터를 기준으로 FPS·메모리 수치도 아직 실측하지 않았습니다.
