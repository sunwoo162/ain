# 의심암귀 V0.8 — 미니맵, 두 시점 비교, 명시적 실행 ID

## 1. 그래프 미니맵

중앙 그래프 오른쪽 위 **FIELD MAP**은 현재 실제로 표시된 노드와 연결을 축소해서 그립니다.

- 밝은 외곽선은 현재 화면에서 보고 있는 영역입니다.
- 미니맵을 클릭하면 그래프 카메라가 해당 위치로 이동합니다.
- 키보드 포커스를 맞춘 후 방향키로 이동할 수도 있습니다.
- 미니맵은 현재 보이는 Cytoscape 노드·엣지만 사용하며, 별도 그래프 엔진이나 네트워크 요청이 없습니다.
- 600 노드·1,800 관계 렌더링 제한은 유지합니다.

## 2. 실행 ID로 묶기

별자리 카드 위의 **연결 기준 / 실행 ID 기준**을 선택합니다.

- **연결 기준:** 기존처럼 실제 엣지 연결 요소를 그룹으로 보여줍니다.
- **실행 ID 기준:** 오직 각 노드의 `traceId`에 명시적으로 부여된 값만 사용합니다.
- trace ID가 없는 노드는 **ID 미지정**으로 표시하고, 기존 연결 관계를 이용해 별도 묶음으로 보여줍니다.
- 실행 ID가 같은 노드는 물리적으로 연결이 없어도 같은 실행 그룹이 됩니다. 하지만 실제 없는 연결선은 그려지지 않습니다.
- 다른 trace ID에 속한 노드를 연결하는 엣지가 있어도 별개 trace 그룹의 관계로 편입하지 않습니다. 전체 관계망에서 원본 연결은 여전히 보입니다.

### SDK로 명시적 ID 보내기

```js
import { randomUUID } from 'node:crypto';
import { createTraceClient } from './sdk/client.mjs';

const traceId=randomUUID(); // API 키나 사용자 식별자를 쓰지 마세요
const client=createTraceClient({token:process.env.MINDTRACE_TOKEN});

await client.send([
  client.node({id:'node-1',kind:'prompt',label:'요청 수신',traceId}),
  client.node({id:'node-2',kind:'model',label:'모델 실행',traceId}),
  client.edge({id:'edge-1',source:'node-1',target:'node-2',kind:'input-to',traceId}),
]);
```

`traceId`는 기존 스키마 1에서 **선택 필드**입니다. 이전 JSON 파일은 그대로 열 수 있습니다.

- 8–80자 영문/숫자/밑줄/하이픈만 허용합니다. 이메일, URL, 텍스트 같은 잠재적 개인정보는 거부합니다.
- OpenAI·Claude·Ollama 어댑터는 자체 생성한 임의 UUID를 사용하며 제공자 응답 ID를 복사하지 않습니다.
- trace ID는 명시적인 실행 구분을 위한 힌트이지 모델이 실제로 어떤 정보를 생각에 사용했는지 증명하지 않습니다.

## 3. 두 시점의 기록 비교

**시간 기록 → 시간 사이의 변화** 패널에서 기준 시점을 조절합니다. 비교 대상은 상단의 이벤트 재생 슬라이더가 가리키는 시점이며 기본값은 최신입니다.

- 저장된 노드와 관계의 **ID**를 대조해 추가·제거·수정된 항목을 집계합니다.
- 입력 데이터가 같은 워크스페이스의 단순 시간 기록일 경우 이전 시점에서 나중 시점으로 갈수록 주로 추가 항목이 나옵니다. 이전 버전으로 바꾼 기록까지 저장·복원한 것은 아닙니다.
- 비교 범위는 전체 워크스페이스입니다. 검색, 별자리 포커스, 줌에 의해 비교 결과가 왜곡되지 않습니다.
- 프롬프트/답변 원문을 추가로 수집하지 않습니다.

## 보안·한계

- 로컬 수집기 인증과 루프백 바인딩 정책을 유지합니다.
- 새 데이터 필드는 현재 trace ID뿐이며 API 키, 원문, 도구 인자는 저장하지 않습니다.
- 미니맵은 현재 표시된 그래프만 보여주므로 600개를 초과해 생략된 노드는 그리지 않습니다.
- 고도화된 OpenTelemetry Trace/Span 구조 자체를 모두 가져오는 기능과 대규모 FPS 벤치마크는 후속 범위입니다.
