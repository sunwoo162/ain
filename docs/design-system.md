# MindTrace — The Observatory UI

## 디자인 목표

시각적 웅장함은 그래프 자체의 관계와 신뢰도를 돋보이게 만드는 방향으로 구현합니다. 화려한 효과가 실제 근거와 추정 관계의 차이를 가리지 않도록 합니다.

### 디자인 시스템

- 바탕: Midnight Navy (#070b15) + 제한된 보라/청록 주변광
- 메인 강조: Violet (#a496ff), Cyan (#6ddff0)
- 노드 색상: 기존 9가지 노드 유형 고유 색상 유지
- 그래프 관계: 실제 관측 실선, 보고/추정 파선, 수동 점선
- 그래프: 은은한 오로라, 궤도 링, 좌표 정보, 큰 캔버스
- 패널: 반투명 심도, 미세한 구분선, 넉넉한 여백
- 애니메이션: 배경 오로라와 상태 신호만. 노드 전체를 상시 이동시키지 않음

### 상호작용

- **Immersive** 버튼: 사이드바와 상세 패널을 접고 그래프 전체 화면에 집중
- **Esc**: Immersive 모드 종료 (입력 필드에 포커스가 있으면 제외)
- **Ctrl+K / Cmd+K**: 검색 필드로 이동
- 선택한 노드: 주변 관계 강조, 나머지 연결 희미하게 표시
- Immersive 모드에서도 선택한 노드의 최소한의 정보 제공
- 화면 너비에 따라 자동 재배치

### 접근성·성능

- `prefers-reduced-motion` 요청 시 장식 애니메이션 비활성화
- 그래프 확대·축소·전체 맞추기 버튼에 기존 접근 가능한 이름 유지
- 패널 기능이나 수집기 토큰 관련 기존 동작 변경 없음
- 궤도/오로라는 포인터 이벤트를 받지 않는 CSS 계층
- 그래프의 실제 노드 수나 출처를 과장하지 않음

## 추후 검증

- Desktop: 1440/1920px, 125% 배율
- Tablet: 768~1180px
- Mobile: 360/390px
- 모션 감소 설정
- 그래프 100 / 1,000 / 10,000개 노드 렌더링 성능 비교 (별도 작업)
- 스크린리더 노드 탐색 기능 강화 (별도 작업)
