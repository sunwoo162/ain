# MindTrace

**An open-source, local-first graph explorer for observable AI activity.**

> Work in progress. Source code and usage instructions will be proposed in a feature pull request.

MindTrace visualizes observed prompts, model calls, retrieval, tool events, evidence summaries and answers. It does **not** expose private model reasoning. Observed access to a document does not prove the model relied on it.
